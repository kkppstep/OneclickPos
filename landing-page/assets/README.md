# assets/

Drop your generated files here using these exact names — the page
looks for them automatically, nothing else to configure.

| File | Used for |
|---|---|
| `bg.jpg` | Full-page ambient background |
| `step-1.jpg` | QR code on the table |
| `step-2.jpg` | Customer scanning |
| `step-3.jpg` | Browsing / ordering |
| `step-4.jpg` | Kitchen sees the order |
| `step-5.jpg` | Owner's phone buzzes |

Missing a file, or haven't generated it yet? Nothing breaks — that
step just shows the original CSS-drawn version until you add it.

Have a **video** instead of a photo for a particular step? See the
main `landing-page/README.md`'s "Adding your generated photos/videos"
section for the one-line HTML swap.
